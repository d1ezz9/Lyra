# Lyra v0.1.0

First public release of the Linux-only music player (AppImage).

**Sources** — Local files, SoundCloud, YouTube Music, Spotify catalog behind one queue. One active source at a time (`Ctrl+1…4`).

**Playback** — mpv engine: gapless queue, shuffle, repeat, seek, replay-gain, fade in/out. Dead/DRM/preview/geo tracks are auto-matched on another platform.

**Downloads** — tracks and whole playlists via yt-dlp (`opus`/`mp3`/`m4a`/`flac`), background auto-download while playing.

**UI** — Material Design 3, 13 themes with live preview, navigation rail + drawer, RU/EN, synced lyrics karaoke.

**Linux-native** — MPRIS2 (`playerctl` works), tray, notifications, XDG paths.

**Requirements** — system `mpv`, `yt-dlp`, `ffmpeg`.

```bash
chmod +x Lyra-0.1.0-x86_64.AppImage
./Lyra-0.1.0-x86_64.AppImage
```

Spotify login needs `LYRA_SPOTIFY_CLIENT_ID` (OAuth PKCE, see README). Full changelog: https://github.com/d1ezz9/Lyra/commits/v0.1.0
